# 🏅 Olympic Athletes Data Analysis

Explore and analyze historical Olympic athlete data using Python to uncover trends in participation, gender distribution, and countries' performance over time.

## 🔍 Project Description
This project involves analyzing the Olympic Games athlete dataset to understand patterns and trends related to participation, gender, events, and medal distribution across countries and years. The analysis helps answer questions such as which countries dominate specific sports, how gender participation has evolved, and how athletes' characteristics vary across sports.

## 🛠️ Tools Used
- **Python**
- **Pandas** – for data manipulation and analysis  
- **Matplotlib** & **Seaborn** – for data visualization  
- **Jupyter Notebook**

## 📂 Project Contents
- `athlete_events1.csv`: The dataset containing detailed information about athletes and Olympic events  
- `Olympic.ipynb`: A Jupyter notebook containing data analysis, visualizations, and insights

## 📈 Analysis Highlights
- Overview of athlete participation by year and gender  
- Country-wise medal tallies and dominance in sports  
- Gender comparison across different events  
- Age distribution of medal winners and average athlete characteristics

## 🧠 Key Findings
- Male participation dominated in earlier years, but female participation has increased significantly over time  
- A few countries consistently perform better in specific sports (e.g., USA in athletics, China in gymnastics)  
- The average age of medal-winning athletes varies by sport
